url-host — 从 URL 列表提取去重 host

读入 URL 列表，输出去重后的 hostname（排查白名单/日志）

仓库
y47y7m71v5/url-host-x9kxs
快速开始 
git clone https://github.com/y47y7m71v5/url-host-x9kxs.git
cd url-host-x9kxs
node bin/hosts.js ./urls.txt
